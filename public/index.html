    WELCOME TO MAILROOM

    A little help, from start to draft.

    1. Choose a sample or paste an email.
    2. Click Analyze email to see a summary and next steps.
    3. Pick a tone, edit your reply, then copy or download it.

    Demo mode uses simple rules and templates, so suggestions will be limited. Live AI uses OpenAI when the server has an API key.

    Gmail connection is optional and read-only. Mailroom never sends email or marks messages as read. Imported emails and drafts stay in memory; disconnecting clears the imported content. Live analysis sends the selected email text to OpenAI only when you click Analyze. You must be the configured owner to connect Gmail.

    To enable live AI, set AI_API_KEY securely on the server and restart it. See the repository README for instructions.
